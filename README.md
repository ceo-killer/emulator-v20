# Эмулятор командной оболочки — вариант №20

Проект реализует эмулятор UNIX-подобной командной оболочки с GUI на
`tkinter`. Виртуальная файловая система загружается из JSON в память.

## Команды

- `ls [путь]` — содержимое директории;
- `cd [путь]` — смена текущей директории;
- `pwd` — текущий путь;
- `date` — текущая дата и время;
- `chmod <права> <путь>` — изменение прав только в памяти VFS;
- `exit` — завершение.

Парсер раскрывает переменные окружения ОС, например `$HOME`.

Все команды записываются в CSV: время, пользователь, команда и ошибка.

## Структура

- `main.py` — запуск и CLI-параметры;
- `src/gui.py` — GUI;
- `src/parser.py` — разбор команд;
- `src/vfs.py` — VFS в памяти;
- `src/commands.py` — команды;
- `src/logger.py` — CSV-логирование;
- `tests/` — автоматические тесты;
- `scripts/` — VFS и тестовые сценарии.

## Запуск

```text
py main.py
```

Или с явными параметрами:

```text
py main.py scripts/vfs_nested.json log.csv scripts/start_success.txt
```

Параметры идут в порядке:

1. путь к VFS;
2. путь к CSV-логу;
3. путь к стартовому скрипту.

## Тесты

```text
py -m unittest discover -s tests -v
```

Windows-сценарии:

```text
scripts\run_minimal.bat
scripts\run_nested.bat
scripts\run_error.bat
scripts\run_invalid_vfs.bat
```

Стартовый скрипт останавливается после первой ошибки. Все изменения
`chmod` выполняются только в памяти и не перезаписывают JSON VFS.
