# Shell Emulator

Эмулятор командной оболочки UNIX-подобной операционной системы.

## 1. Общее описание

Проект представляет собой графический прототип командной оболочки UNIX-подобной системы. Интерфейс реализован с помощью библиотеки `tkinter`.

Пользователь вводит команды в окне программы, после чего эмулятор разбирает строку, определяет команду и аргументы, выполняет обработчик и показывает результат или сообщение об ошибке.

На первом этапе реализованы команды-заглушки `ls` и `cd`, команда завершения `exit`, раскрытие переменных окружения операционной системы и обработка неизвестных команд. На втором этапе добавлены параметры запуска, CSV-журналирование и автоматическое выполнение стартового скрипта.

В рамках этих этапов `ls` и `cd` выводят название команды и переданные аргументы; реальная навигация по виртуальной файловой системе не выполняется.

## 2. Описание всех функций и настроек

- `main.py`: точка входа; принимает три обязательных параметра командной строки:
  - `vfs_path` — путь или имя виртуальной файловой системы, отображаемое в заголовке окна;
  - `log_path` — путь к CSV-файлу журнала;
  - `script_path` — путь к стартовому скрипту.

- `src/gui.py`: графический интерфейс на `tkinter`, интерактивный ввод команд, вывод результатов и ошибок, запуск стартового скрипта.

- `src/parser.py`: раскрытие переменных окружения с помощью `os.path.expandvars` и разбор команды с аргументами с помощью `shlex.split`. Некорректные кавычки приводят к понятному сообщению об ошибке.

- `src/commands.py`: обработчики команд:
  - `ls [аргументы]` — выводит название команды и переданные аргументы;
  - `cd [аргументы]` — выводит название команды и переданные аргументы;
  - `exit` — завершает работу; дополнительные аргументы запрещены.

- `src/vfs.py`: хранит заданное имя VFS для заголовка окна. На данном этапе содержимое файловой системы не загружается.

- `src/logger.py`: записывает события в CSV. Столбцы: время, имя пользователя ОС, введённая команда, сообщение об ошибке.

- `scripts/`: стартовые сценарии и сценарии запуска для проверки параметров командной строки.

- `tests/`: автоматические тесты парсера, командных заглушек, параметров запуска, CSV-журнала и стартовых сценариев.

Стартовый скрипт выполняется построчно. При ошибке выполнения он останавливается и выводит сообщение. Команда `exit` завершает скрипт штатно, не обозначаясь как ошибка.

## 3. Описание команд для сборки проекта и запуска тестов

Для запуска на macOS или Linux необходимо указать три параметра:

```bash
python3 main.py vfs.json log.csv scripts/start.txt
```

На Windows:

```text
py main.py vfs.json log.csv scripts/start.txt
```

Запуск автоматических тестов на macOS или Linux:

```bash
python3 -m unittest discover -s tests -v
```

На Windows:

```text
py -m unittest discover -s tests -v
```

Сценарии запуска, проверяющие разные значения всех трёх параметров, расположены в каталоге `scripts/`. Примеры для Windows имеют расширение `.bat`, для macOS/Linux — `.sh`.

## 4. Примеры использования

Пример запуска с явными параметрами:

```bash
python3 main.py scripts/demo-vfs.json log.csv scripts/start.txt
```

Примеры команд в графическом окне:

```text
ls
```

Выводит название команды `ls`.

```text
ls -l /home/student
```

Выводит команду и её аргументы: `ls -l /home/student`.

```text
cd /home/student
```

Выводит команду и переданный путь как аргумент заглушки.

```text
cd $HOME
```

Перед выполнением переменная окружения `$HOME` раскрывается в значение из операционной системы.

```text
unknown_command
```

Эмулятор выводит сообщение о неизвестной команде и записывает ошибку в CSV-журнал.

```text
exit
```

Завершает работу программы.

Файл `scripts/start.txt` содержит команды, которые выполняются автоматически после запуска. В `scripts/start_error.txt` специально добавлена неизвестная команда: выполнение сценария должно остановиться на ней.
